OpenLoco v26.07.1 is out! Only one day after v26.07, unfortunately. We're patching a few bugs in this one!

Please find the [download](https://openloco.io/download/) on our website, or read the
[changelog](https://github.com/OpenLoco/OpenLoco/blob/v26.07.1/CHANGELOG.md) on GitHub.


## Fixed initial game setup

You may have read in [yesterday's announcement](https://openloco.io/news/2026/07/openloco-v26.07.html)
that we reworked the game initialisation functions. This was all fine and good, _unless_ you had
no game config yet, e.g. when you had never played the game before on your machine. In that case,
we normally show a popup asking you where *Locomotion* has been installed, leading you into a file browser
where you can select the right folder. It was that last part that broke. Oops. It's fixed now!
[(#3844)](https://github.com/OpenLoco/OpenLoco/pull/3844)


## Raise the limit of audio sources, fix the lag when the limit is reached

@LeftOfZen noticed extreme lag on large maps with many vehiclees. It turned out that in this edge case
the game quickly reaches the limit for the engine, OpenAL. By default, it can handle 256 sources at once,
after which you're not supposed to add more. Well, we continued adding more anyway, triggering (invisible)
errors and therefore lag.

The limit has been increased to 1024 sources, and we now actually _stop_ adding more audio sources
once the limit has been reached. [(#3841)](https://github.com/OpenLoco/OpenLoco/pull/3841)
