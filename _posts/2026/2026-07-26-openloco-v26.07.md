OpenLoco v26.07 is out! This month's release incorporates changes made both this month and last as we didn't have enough to put into a dedicated 26.06 release. As such, we've got some quality-of-life additions to UI, bug fixes for window and chart rendering, plenty of under-the-hood engine work, improvements to the codebase itself in terms of cleanliness and maintainability, updated translations, and plenty of shiny new OpenGraphics objects!

## Gameplay Features & UI Enhancements
Several new user interface additions improve the display of gameplay statistics and quality-of-life navigation. Industry windows now display cargo stats for awaiting processing and transport, town windows feature a dedicated transported cargo tab, and audio options have been expanded with a music playback toggle and a direct jukebox button. File browsing now includes a convenient "Home" button, and lastly there were some minor spelling updates for English translations.

## Bug Fixes & Stability
A range of visual, logic, and operational bugs have been resolved, such as fixing off-by-one rendering errors in the terraforming tool, correcting population chart overflows, restoring resize handles on affected windows, and fixing an issue where the Locomotion data path CLI option was being ignored. Tutorial behaviour was also improved by having the game options reset back to the users' settings after the tutorial completes.

## Performance, Engine Optimisation, Input
Under the hood we have some noticeable performance gains, particularly in loop-heavy operations; yearly in-game updates and object iteration across map tiles  were optimised. Memory overhead and lookups were also streamlined by replacing std::map usage in cursor storage and refactoring how tile elements are held in memory. There was a refactor to window event handling, as well as tidying up AI pathfinding logic. Additionally, shortcuts/keybinds were improved considerably, now showing you a visual preview of what keys are being pressed as well as well as improvement of the underlying code handling these inputs.
